# memo-init

memo-init is a memo-driven, agentic software-engineering system. Work begins with a dense memo
that is iterated into a finalized plan before any code is written, then rolled out autonomously
along a Generate → Execute → Evaluate loop. This organization is the inductive RFC specification
of that system — the daily-productive memo toolkit written up as a public, standalone spec.
Publication secures authorship of the approach. FlowMCP serves as the structural role model:
an RFC-style spec, a generated org profile, a documentation site, and a small set of focused repos.

[Documentation →](https://memo-init.github.io)
